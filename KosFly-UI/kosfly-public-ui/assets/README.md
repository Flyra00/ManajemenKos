# Assets — KosFly Public UI

Folder ini disediakan untuk menyimpan aset statis (logo, favicon, gambar,
og-image, dsb.) saat nanti diintegrasikan ke proyek Laravel KosFly.

Saat ini seluruh visual pada landing page, login, dan register dibangun
murni dengan HTML + CSS + inline SVG sehingga tidak bergantung pada file
gambar eksternal maupun CDN yang tidak stabil.
